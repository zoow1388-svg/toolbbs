# v0.9 回传唤醒验证

验证日期：2026-09-15

## 真实结果

- 执行任务向正在等待的总控任务主动发送带唯一事件 ID 的消息，等待操作被新输入立即打断，总控收到回传。
- 执行任务向同项目中原本处于 idle 的接收任务发送第二个事件，接收任务自动开始新一轮并返回预期 ACK。
- 两次发送接口均成功，但宿主只返回目标任务 ID，没有消息 ID。
- 测试前后 Git 提交一致且工作区干净；任务未创建、修改或删除项目文件。

真实任务 ID 不写入本报告。现场结果证明 Codex 桌面宿主运行时支持任务间主动回传并唤醒等待或 idle 的任务。

## 产品结论

发送接口成功不能单独证明可靠交付。v0.9 使用唯一回传事件、总控接收回执、SHA-256 和反向 ACK 建立可审计闭环。整个 Codex 应用退出或电脑离线时不承诺即时唤醒，只保证宿主恢复后可依据持久化状态继续。
